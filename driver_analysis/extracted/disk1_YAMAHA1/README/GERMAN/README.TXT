3.0 INSTALLATIONSHINWEISE FÜR OPL3-SA IN DER 
HANDELSÜBLICHEN WINDOWS 95-VERSION 
-------------------------------------------- 
Diese Installationshinweise gehen davon aus, daß Sie 
Windows 95 bereits ordnungsgemäß auf Ihrem Computer 
installiert haben und daß Ihr System fehlerfrei 
gestartet werden kann. Falls das nicht der Fall ist, 
siehe die Bedienungsanleitung von Windows 95.

1. Klicken Sie auf Start und wählen Sie Einstellungen. 
2. Klicken Sie auf Systemsteuerung. 
3. Doppelklicken Sie das System-Symbol. 
4. Klicken Sie auf die Geräte-Manager-Zunge und 
   anschließend auf das Andere Komponenten-Symbol. 
5. Klicken Sie auf das erste unbekannte Gerät und 
   anschließend auf Entfernen. 
6. Klicken Sie auf OK, um den Befehl zu bestätigen. 
7. Klicken Sie auf das zweite unbekannte Gerät und 
   anschließend auf Entfernen. 
8. Bestätigen Sie diesen Befehl, indem Sie auf OK 
   klicken. 
9. Klicken Sie auf Aktualisieren. 
10.Wenn eine diesbezügliche Meldung erscheint, wählen 
   Sie Treiber auf Diskette des Hardware-Herstellers. 
11.Klicken Sie auf OK. 
12.Klicken Sie auf Durchsuchen. 
13.Wählen Sie unter Laufwerk den Buchstaben des 
   Laufwerks, in dem sich die Diskette Yamaha Drivers 
   Disk befindet. 
14.Klicken Sie auf OK. 
15.Klicken Sie noch einmal auf OK. 
16.Legen Sie die Windows* 95 CD/Diskette in das 
   Laufwerk, sobald Sie dazu aufgefordert werden. 
17.Starten Sie Ihren Computer neu, um die Installation 
   zu beenden.

---------------------------------------------- 
4.0 INSTALLATIONSHINWEISE FÜR OPL3-SA IN EINER 
OEM-VERSION VONWINDOWS 95 
---------------------------------------------- 
Verfahren Sie folgendermaßen wenn Sie die Treiber 
sofort nach Installieren des Windows 95-Systems 
installieren. Nach der Installation wird das Yamaha 
Sound System als Anderes Gerät geführt.

1. Während der Installation von Windows 95 wird das 
   Audiogerät als Unbekanntes Gerät erkannt. Daher wird 
   vorgeschlagen, den Wizard für die Installation des 
   Treibers zu verwenden. 
2. Legen Sie die erste Diskette des Audio-Treibers in 
   das Diskettenlaufwerk. 
3. Klicken Sie auf Weiter. 
4. Windows 95 zeigt nun an, daß das Yamaha OPL3-SAx 
   Sound System gefunden wurde. 
5. Klicken Sie auf Beenden. 
6. Geben Sie das Diskettenlaufwerk im Bedarfsfall noch 
   einmal an. 
7. Nun wird der Game-Port entdeckt und installiert. 
   Wenn nötig, bittet Windows 95 Sie, die Windows 95-CD 
   einzulegen, um die Installation des Joystick-Treibers 
   zu beenden.

5.0 INSTALLATIONSHINWEISE FÜR OPL3-SA2 oder OPL3-SA3 
IN DER HANDELSÜBLICHEN WINDOWS 95-VERSION 
---------------------------------------------------- 
1. Klicken Sie auf dem Arbeitsplatz auf den 
   START-Button, wählen Sie EINSTELLUNGEN und danach 
   SYSTEMSTEUERUNG. 
2. Doppelklicken Sie auf das SYSTEM-Symbol und wählen 
   Sie die GERÄTE-MANAGER-Zunge. Wenn es dort einen 
   ANDERE Komponenten-Eintrag gibt, müssen Sie darauf 
   doppelklicken, damit diese Kategorie aufgerollt wird. 
   Wenn sich dort ein OPL3-SA2 oder OPL3-SA3 SOUND 
   CARD-Eintrag befindet, wählen Sie ihn und klicken 
   anschließend auf ENTFERNEN. 
3. Scrollen Sie entlang der Geräteübersicht und 
   doppelklicken Sie auf AUDIO-, VIDEO- UND 
   GAME-CONTROLLER, damit dieser Eintrag geöfnnet wird. 
   Dort sehen Sie eine Liste aller Geräte, die bereits 
   installiert sind. Wählen Sie der Reihe nach alle 
   Soundkarten und Game-Ports und klicken Sie jeweils auf 
   ENTFERNEN. 
4. Wählen Sie OK, um den GERÄTE-MANAGER sowie das 
   Systemsteuerung wieder zu schließen. 
5. Legen Sie die YAMAHA-Treiberdiskette in Laufwerk 
   A oder B. 
6. Wählen Sie START | AUSFÜHREN, geben Sie 
   A:\SAUNINST.EXE ein und klicken Sie auf OK, um 
   fortzufahren. 
   (Achtung: Geben Sie B:\SAUNINST.EXE ein, wenn Sie den 
   Treiber von Laufwerk B aus installieren.) 
7. Wählen Sie auf der ersten OPLSAx-Seite WEITER. 
   Klicken Sie noch einmal auf WEITER, um fortzufahren. 
8. Wenn die Meldung "Deinstallation beendet" erscheint, 
   klicken Sie auf BEENDEN. 
9. Entnehmen Sie die Diskette und klicken Sie auf OK, 
   um den Computer neuzustarten. 
10.Ihr Computer wird nun neugestartet. Als erstes wird 
   nun die Meldung "NEUE HARDWAREKOMPONENTE GEFUNDEN" 
   angezeigt, die sich natürlich aufdie OPL3-SA2- oder 
   OPL3-SA3-Karte bezieht (je nachdem, welche Sie 
   installiert haben.) 
11.Legen Sie die YAMAHA-Treiberdiskette in das 
   Diskettenlaufwerk. 
12.Wählen Sie "Treiber auf Diskette des 
   Hardware-Herstellers" und klicken Sie auf OK, um 
   fortzufahren. 
13.Im nächsten Fenster (Installieren von Diskette) 
   geben Sie entweder A: oder B: ein, je nachdem, 
   welches Laufwerk Sie verwenden. Klicken Sie auf OK, 
   um fortzufahren. 
14.Ihr System kopiert nun die benötigten Dateien zur 
   Festplatte. 
15.Nach dem Kopieren weiterer Datein, kann es vorkommen, 
   daß Sie gebeten werden, die Windows 95 CD-ROM 
   einzulegen und auf OK zu klicken. 
16.Wenn diese Meldung bei Ihnen erscheint, legen Sie 
   Ihre Windows 95 CD-ROM in den Schlitten. 
17.Klicken Sie auf OK und geben Sie D:\WIN95 
   (bzw. den Buchstaben Ihres CD-ROM-Laufwerks) ein und 
   klicken auf OK, um fortzufahren. 
18.Wenn die Klangqualität nicht optimal ist oder wenn 
   die Karte nicht erwartungsgemäß funktioniert, wählen 
   Sie START | BEENDEN | WINDOWS NEU STARTENS und 
   klicken auf OK. Ihr Computer wird nun neugestartet. 
   Im Prinzip hören Sie nun die 
   Windows 95-Erkennungsmelodie.

7.0 HINWEISE FÜR DAS ÜBERSCHREIBEN 
---------------------------------- 
Wenn Ihr System bereits ältere Yamaha Sound 
System-Treiber enthält:
1. Starten Sie "SAuninst.exe" auf der ersten 
   Treiberdiskette. 
2. Wenn Sie darum gebeten werden, entnehmen Sie die 
   Diskette und starten den Computer neu. 
3. Legen Sie die erste Treiberdiskette im Bedarfsfall 
   in dasLaufwerk. 
4. Wenn Sie nicht gebeten werden die Diskette 
   einzulegen, kontrollieren sie den Geräte-Manager, 
   entfernen alle Yamaha-Einträge und starten den 
   Computer neu. 
5. Siehe obige Treiberinstallationshinweise.

8.0 HARDWARE WAVETABLE-WIEDERGABE ODER VERWENDUNG DER 
OPL4-ML 
----------------------------------------------------- 
Wenn Ihr System über eine Hardware Wavetable-Karte oder 
eine OPL4-ML verfügt, können Sie die Hardware Wavetable 
für die Wiedergabe von Standard MIDI-Files aktivieren.
1. Doppelklicken Sie auf Arbeitsplatz. 
2. Doppelklicken Sie auf den SYSTEMSTEUERUNG-Eintrag. 
3. Doppelklicken Sie auf den MULTIMEDIA-Eintrag. 
4. Klicken Sie im Eigenschaften von Multimedia-Fenster 
   auf die MIDI-Zunge.
5. Wählen Sie YAMAHA OPL3-SA MPU401. 
6. Klicken Sie auf OK. 
7. Öffnen Sie Media Player 
   über START | PROGRAMME | ZUBEHÖR | MULTIMEDIA | 
   Medienwiedergabe. 
8. Sobald Medienwiedergabe geöffnet ist, klicken Sie auf 
   Datei. 
9. Wählen Sie Öffnen. 
10.Wählen Sie eine MIDI-Datei. In der Regel enthält der 
   \Windows\Media-Ordner eine Reihe von MIDI-Dateien. 
11.Nun können Sie die MIDI-Dateien mit der Hardware 
   Wavetable abspielen. Klicken Sie auf den 
   Wiedergabetaster des Medienwiedergabe.

-------------------------------------- 
9.0 WIEDERGABE VON SOFTWARE WAVETABLES 
-------------------------------------- 
1. Klicken Sie auf Start, wählen Sie Einstellungen und 
   anschließend Systemsteuerung. 
2. Doppelklicken Sie auf das Multimedia-Symbol. 
3. Wählen Sie Yamaha OPL3SA SoftSynth und klicken sie 
   auf OK. 
4. Öffnen Sie einen Medienwiedergabe und starten Sie die 
   Wiedergabe eines Standard MIDI Files. 
   Im WT-Programm des Mixers können Sie die Lautstärke 
   und Balance der Software Wavetable-Musik einstellen. 
5. Klicken Sie auf Start, wählen Sie Einstellungen und 
   Systemsteuerung. 
6. Doppelklicken Sie auf das OPL3-SAx Config-Symbol und 
   ändern Sie die Qualitätsstufe, um die Klangqualität 
   zu verbessern.

-------------------------------------------------- 
10.0 SIMULTANWIEDERGABE VON SOFTWARE WAVETABLE UND 
WAVE-DATEIEN 
-------------------------------------------------- 
1. Klicken Sie auf Start, auf Einstellungen und auf 
   Systemsteuerung. 
2. Doppelklicken Sie auf das OPL OPL3-SAx Config-Symbol. 
3. Stellen Sie die gewünschte Qualität, den Hall sowie. 
4. Klicken Sie auf OK.

----------------------------------------------- 
11.0 VERWENDUNG VON SOFTWARE WAVETABLE IN EINEM 
VIRTUELLEN DOS-FENSTER 
-----------------------------------------------
1. Klicken Sie auf Start, wählen Sie Einstellungen und 
   anschließend Systemsteuerung. 
2. Doppelklicken Sie auf das OPL3-SAx Config-Symbol. 
3. Stellen Sie den Qualität-, Reverb-Parameter ein. 
4. Stellen Sie MPU401-Ausgang auf Soft GM. 
5. Klicken Sie auf OK. 
6. Stellen Sie das DOS-Programm so ein, daß es General 
   MIDI oder MPU401 unter der I/O-Adresse 330 sucht. 
7. Starten Sie das DOS-Programm. Die Klangqualität ist 
   nun besser als bei Verwendung der normalem 
   FM-Synthese.
