3.0 市販のWINDOWS 95へのOPL3-SAのインストール手順
-------------------------------------------------
以下の説明では、お使いのコンピュータにWindows95を正しくインストールしてあり、
システムがエラーなく起動、作動することを想定しています。これが当てはまらない
場合は、作業を続ける前にWindows95のユーザ・マニュアルを参照ください。

1.  スタートをクリックしてから設定にポインタを置きます。
2.  [コントロール パネル]をクリックします。
3.  システムアイコンをダブルクリックします。
4.  [デバイスマネージャ]タブをクリックしてから、[その他のデバイス]の横にある
    プラスの記号をクリックします。
5.  最初の未知のデバイスでクリックしてから削除をクリックします。
6.  OKをクリックしてデバイスの削除を確定します。
7.  次の未知のデバイスでクリックしてから削除をクリックします。
8.  OKをクリックしてデバイスの削除を確定します。
9.  更新をクリックします。
10. プロンプトで、[ハードウエアの製造元が提供するドライバ]からDriverを選択し
    ます。
11. OKをクリックします。
12. 参照をクリックします。
13. Driveで、Yamaha Audio Drivers Diskの入っているドライブの文字を選択しま
    す。
14. OKをクリックします。
15. OKをもう一度クリックします。
16. プロンプトが表示されたらWindows 95 CD/ディスクを挿入します。
17. コンピュータを再起動すればインストール完了です。

-------------------------------------------
4.0 OEM WINDOWS 95へのOPL3-SAのインストール
-------------------------------------------
Windows95オペレーティング・システムをインストールした後すぐにデバイス・ドラ
イバをインストールする場合は、次の手順に従ってください。インストール時Yamaha
 Sound Systemは[その他のデバイス]となります。

1. Windows 95のインストール中、Windows95はオーディオ・デバイスを未知のデバ
   イスとして認識し、Update Device DriverWizardがドライバのインストールを行
   うことをユーザに知らせます。
2. オーディオ・デバイス・ドライバの入っている最初のディスクを挿入します。
3. 次へをクリックします。
4. Windows 95がYamaha OPL3-SAx Sound Systemを見つけたことを知らせます。
5. 完了をクリックします。
6. 必要に応じてディスク・ドライブにポインタを置きます。
7. ゲームポートが検出されインストールされます。Windows95のプロンプトがあれば
   、Windows 95CDを挿入して、ジョイスティック・ドライバのインストールを終了し
   ます。

5.0 市販のWINDOWS 95へのOPL3-SA2またはOPL3-SA3のインストール
------------------------------------------------------------
1.  Windows95のデスクトップからスタートボタンをクリックし、設定を選択してから
    [コントロール パネル]を選択します。
2.  システムアイコンでダブルクリックし、[デバイスマネージャ]タブを選択します。
    [その他のデバイス]という名前のエントリがあったらこれをダブルクリックして、
    このカテゴリをドロップダウンします。OPL3-SA2またはOPL3-SA3 SOUNDCARDという
    エントリがある場合はこれをハイライト表示させて削除をクリックします。
3.  デバイス・リストをスクロールダウンして[サウンド、ビデオ、およびゲームのコ
    ントローラ]をクリックしてこれをドロップダウンします。すでにインストールし
    てあるデバイスのリストが表示されます。すでにインストールした任意のサウン
    ドカードとゲームポートを選択して、それぞれ削除をクリックします。
4.  OKを選択して[デバイス マネージャ]を閉じ、[コントロール パネル]を閉じます。
5.  YAMAMAドライバ・ディスクをディスク・ドライブAまたはBに挿入します。
6.  スタート | ファイル名を指定して実行を選択してA:\SAUNINST.EXEと入力し、OK
    を押して続行します。(注:Bドライブでインストールを行っている場合は、
    B:\SAUNINST.EXEと入力します。)
7.  最初のOPLSAx画面で次へを選択します。もう一度次へをクリックして続行します。
8.  "Uninstall Completed"という画面が出たら、完了をクリックします。
9.  ディスクを取り出して、OKをクリックしてコンピュータを再起動します。
10. コンピュータが再起動します。最初の画面に"新しいﾊｰﾄﾞｳｪｱ"というメッセージが
    現われます。これはお使いのオーディオデバイスによってOPL3-SA2または
    OPL3-SA3のSound Boardを指します。
11. YAMAHAドライバ・ディスクをディスク・ドライブに挿入します。
12. [ハードウエアの製造元が提供するドライバ]を選択し、OKをクリックして続行し
    ます。
13. 次の画面で(フロッピーからのインストールの場合)、お使いのディスク・ドライ
    ブに従ってA:またはB:を入力します。
14. ハード・ドライブへのファイルのコピーが始まります。
15. ファイルがハード・ディスクにコピーされると、"Windows 95 CD-ROM ラベルの
    付いたディスクを挿入してOKを押して下さい。"というメッセージが出ます。
16. このメッセージが出たらCD-ROMドライブにWindows 95 CD-ROMを挿入します。
17. ここでOKをクリックし、D:\WIN95(またはお使いのシステムに該当するCD-ROMド
    ライブの文字)を入力し、OKをクリックして続行します。
18. サウンドがクリアでない場合、または正しい音が出ない場合は、スタート |
    Windowsの終了 | コンピューターを再起動するを選んでYesをクリックします。
    コンピュータが再起動し、その際にWindows95のサウンドが聞こえます。

7.0 上書きインストールの手順
----------------------------
システムにYamaha SoundSystemデバイス・ドライバの以前のバージョンが入っている
場合:

1.  最初のドライバ・ディスクから"SAuninst.exe"を起動します。
2.  プロンプトでシステムを再起動し、ドライバ・ディスクを取り出します。
3.  再起動後プロンプトが表示されたら、最初のドライバ・ディスクを挿入します。
4.  ドライバ・ディスクを挿入するプロンプトが表示されない場合は、[デバイス
    マネージャ]をチェックしてYamahaの名前が入ったエントリを取り除き、再起動し
    ます。
5.  前述のデバイス・ドライバのインストール手順に従います。

8.0 ハードウエア・ウエーブテーブルの再生またはOPL4-MLの使用
-----------------------------------------------------------
システムにハードウエア・ウエーブテーブル・カードが搭載されている場合、または
OPL4-MLがインストールされている場合は、ハードウエア・ウエーブテーブルでMIDI
ファイルの再生ができます。

1.  マイコンピュータをクリックします。
2.  コントロールパネルアプレットをクリックします。
3.  マルチメディアアプレットをクリックします。
4.  マルチメディアプロパティ・ウインドウでMIDIタブをクリックします。
5.  YAMAHA OPL3-SA MPU401をハイライト表示させます。
6.  OKをクリックします。
7.  スタート | プログラム | アクセサリ | マルチメディア | メディアプレーヤー
    に進みMIDIタブをクリックします。.
8.  メディアプレーヤーが開いたらファイルをクリックします。
9.  開くをハイライト表示させて選択します。
10. MIDIファイルにポインタを置いて選択します。MIDIファイルは通常
    \Windows\Mediaディレクトリに入っています。
11. これでハードウエア・ウエーブテーブルを使ってMIDIファイルを再生できます。
    メディアプレーヤーの再生ボタンをクリックしてください。

----------------------------------------
9.0 ソフトウエア・ウエーブテーブルの再生
----------------------------------------
1.  スタートをクリックし、設定にポインタを置いて[コントロールパネル]をクリッ
    クします。
2.  マルチメディアアイコンをダブルクリックします。
3.  Yamaha OPL3SA SoftSynthを選択しOKをクリックします。
4.  メディア・プレーヤを開いてMIDIファイルを再生します。ミキサーのソフトウェ
    ア WTセクションを使って、ソフトウエア・ウエーブテーブル・サウンドの音量
    とバランスを調整します。
5.  スタートをクリックし、設定にポインタを置いて[コントロールパネル]をクリッ
    クします。
6.  OPL3-SAxの設定アイコンをダブルクリックし、音質設定を調整してサウンド・ク
    オリティを向上させます。

-----------------------------------------------------------------
10.0 ソフトウエア・ウエーブテーブルとウエーブ・ファイルの同時再生
-----------------------------------------------------------------
1.  スタートをクリックし設定にポインタを置いて[コントロールパネル]をクリック
    します。
2.  OPL3-SAxの設定アイコンをダブルクリックします。
3.  音質、リバーブを設定します。
4.  OKをクリックします。

----------------------------------------------------------------------------
11.0 VIRTUAL DOS BOXアプリケーションでのソフトウエア・ウエーブテーブルの使用
----------------------------------------------------------------------------
1.  スタートをクリックし設定にポインタを置いて[コントロールパネル]をクリック
    します。
2.  OPL3-SAxの設定アイコンをダブルクリックします。
3.  音質、リバーブを設定します。
4.  MPU401 OUTをソフトGMに設定します。
5.  OKをクリックします。
6.  GeneralMIDIまたはMPU401をI/Oアドレス330で使用するようDOSアプリケーション
    をセットアップします。
7.  DOSアプリケーションを起動します。通常のFMシンセサイザーと比較して音質が向
    上するはずです。

-------------------------------
12.0 「省電力アプレット」の使用
-------------------------------
Version 4.03.2320 より「省電力アプレット」が添付されました。
これは、Windows95上でOPL3-SAx のパワーセーブをコントロールするためのものです。
