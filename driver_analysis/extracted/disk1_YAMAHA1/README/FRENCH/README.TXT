-------------------------------------------------
3.0 INSTRUCTIONS D’INSTALLATION POUR OPL3-SA SOUS 
WINDOWS 95 COMMERCIAL 
------------------------------------------------- 
Ces instructions partent du principe que vous avez 
correctement installé Windows 95 sur votre ordinateur 
et que votre système est capable de se mettre en marche 
et de tourner sans erreur. Si ce n’est pas le cas, 
veuillez consulter le manuel de Windows 95 avant de 
poursuivre.

1. Cliquez sur Démarrer et pointez Paramètres. 
2. Cliquez sur Panneau de configuration. 
3. Double-cliquez sur l’icône Système. 
4. Cliquez sur l’onglet Gestionnaire de périphériques 
   puis cliquez sur le signe plus situé en face de 
   l’intitulé Autres périphériques. 
5. Cliquez sur le premier périphérique inconnu puis 
   cliquez sur Supprimer. 
6. Cliquez sur OK pour confirmer la suppression du 
   périphérique. 
7. Cliquez sur le deuxième périphérique inconnu puis 
   cliquez sur Supprimer. 
8. Cliquez sur OK pour confirmer la suppression du 
   périphérique. 
9. Cliquez sur Rafraîchir. 
10.Lorsque la demande en est faite, sélectionnez le 
   pilote fourni sur la disquette du constructrur 
   du matériel. 
11.Cliquez sur OK. 
12.Cliquez sur Parcourir. 
13.Sous Lecteur, sélectionnez la lettre correspondant 
   au lecteur contenant la disquette des pilotes 
   Yamaha Audio. 
14.Cliquez sur OK. 
15.Cliquez une fois de plus sur OK. 
16.Insérez le CD ou la disquette Windows* 95 si on vous 
   le demande. 
17.Redémarrez l’ordinateur pour conclure l’installation.

4.0 INSTRUCTIONS D’INSTALLATION POUR OPL3-SA SOUS 
WINDOWS 95 OEM 
-------------------------------------------------
Suivez ces instructions lorsque vous installez les 
pilotes de périphériques immédiatement après avoir 
installé le système de fonctionnement de Windows 95. 
Une fois installé, le Yamaha Sound System est rangé 
sous Autres périphériques.

1. Durant l’installation de Windows 95, Windows 95 
   détecte le périphérique audio sous forme de 
   Périphérique inconnu et signale à l’utilisateur que 
   l’Assistant terminera l’installation du pilote. 
2. Insérez la première disquette contenant le pilote du 
   périphérique audio. 
3. Cliquez sur Suivant. 
4. Windows 95 annonce alors que le Yamaha OPL3-SAx Sound 
   System a été trouvé. 
5. Cliquez sur Terminer. 
6. Repointez sur le lecteur de disquette si nécessaire. 
7. Le port jeux sera alors détecté et installé. Si 
   Windows 95 le demande, insérez le CD Windows 95 pour 
   terminer l’installation du pilote du joystick.

5.0 INSTRUCTIONS D’INSTALLATION POUR OPL3-SA2 OU 
OPL3-SA3 POUR WINDOWS 95 COMMERCIAL 
------------------------------------------------ 
1. Du poste de travail Windows 95, cliquez sur Démarrer 
   et pointez Paramètres. Cliquez sur Panneau de 
   configuration. 
2. Double-cliquez sur l’icône Système. Cliquez sur 
   l’onglet Gestionnaire de périphériques. Si vous 
   voyez une rubrique appelée AUTRES PERIPHERIQUES, 
   double-cliquez dessus. Si vous voyez un intitulé 
   OPL3-SA2 ou OPL3-SA3 SOUND CARD, contrastez-le et 
   cliquez sur SUPPRIMER. 
3. Faites défiler la liste de périphériques et 
   double-cliquez sur Contrôleurs son, vidéo et jeux 
   pour l’ouvrir. Vous verrez alors une liste de 
   périphériques installés préalablement. Sélectionnez 
   n’importe quelle carte son et port jeux installé et 
   cliquez sur Supprimer pour chacun. 
4. Sélectionnez OK pour fermer le Gestionnaire de 
   périphériques et fermer le Panneau de configuration. 
5. Insérez la disquette du pilote YAMAMA dans le 
   lecteur A ou B. 
6. Sélectionnez Démarrer | Exécuter et tapez 
   A:\SAUNINST.EXE puis appuyez sur OK pour continuer. 
   (Remarque: Si vous utilisez le lecteur B pour votre 
   installation, remplacez par le texte suivant: 
   B:\SAUNINST.EXE). 
7. Dans le premier affichage OPLSAx, sélectionnez 
   Suivant. Cliquez une fois de plus sur Suivant pour 
   poursuivre. 
8. Lorsque vous voyez le message "Désinstallation 
   terminée" cliquez sur Terminer. 
9. Enlevez votre disquette et cliquez sur OK pour 
   redémarrer l’ordinateur. 
10.Votre ordinateur redémarre. Le premier écran que 
   vous voyez "Nouveau périphérique détecté" fait 
   allusion à une carte son OPL3-SA2 ou OPL3-SA3, selon 
   votre configuration audio.
11.Insérez la disquette du pilote YAMAMA dans le 
   lecteur. 
12.Sélectionnez "Pilote de la disquette fournie" et 
   cliquez sur OK pour continuer. 
13.A l’écran suivant (installation à partir de la 
   disquette), entrez soit A: soit B: selon le lecteur 
   de disquette utilisé. 
   Cliquez ensuite sur OK pour continuer. 
14.Votre système va commencer à copier des fichiers sur 
   le disque dur. 
15.Une fois que les fichiers supplémentaires ont été 
   copiés sur le disque dur, le message suivant peut 
   s’afficher: "Veuillez insérer le CD-ROM Windows 95 
   et cliquez ensuite sur OK. 
16.Dans ce cas, insérez votre CD-ROM Windows. 
17.Cliquez sur OK, entrez D:\WIN95 (ou la lettre 
   correspondant au lecteur de CD-ROM sur votre système) 
   et cliquez sur OK pour continuer. 
18.Si votre son n’est pas clair ou ne donne pas un bon 
   résultat, 
   sélectionnez DEMARRER | ARRETER | REDEMARRER 
   L’ORDINATEUR et cliquez sur Oui. Votre ordinateur 
   redémarre comme le confirme la tonalité de démarrage 
   de Windows 95.

7.0 INSTRUCTIONS DE SURINSTALLATION 
----------------------------------- 
Si votre système comporte une version antérieure des 
pilotes pour périphériques Yamaha Sound System:
1. Exécutez "SAuninst.exe" sur la première disquette du 
   pilote. 
2. Lorsque l’ordinateur vous le demande, redémarrez 
   votre système et éjectez la disquette du pilote. 
3. Après le redémarrage, insérez la première disquette 
   du pilote si la demande en est faite.
4. Si cette demande n’est pas faite, contrôlez le 
   Gestionnaire de périphériques, supprimez tous les 
   intitulés concernant Yamaha et redémarrez. 
5. Suivez les instruction concernant l’installation des 
   pilotes de périphériques données ci-dessus.

8.0 UTILISATION D’UNE HARDWARE WAVETABLE OU D’UN 
OPL4-ML 
------------------------------------------------ 
Si votre système est doté d’une carte Hardware Wavetable 
ou de l’OPL4- ML, vous pouvez activer la Hardware 
Wavetable pour reproduire des fichiers MIDI.
1. Double-cliquez sur le Poste de travail. 
2. Double-cliquez sur le Panneau de configuration. 
3. Double-cliquez sur Multimédia. 
4. Cliquez sur l’onglet MIDI de la fenêtre Propriétés 
   pour Multimédia. 
5. Contrastez YAMAHA OPL3-SA MPU401. 
6. Cliquez sur OK. 
7. Ouvrez le lecteur multimédia en passant par 
   DEMARRER | PROGRAMMES | ACCESSOIRES | LECTEUR 
   MULTIMEDIA. 
8. Une fois le lecteur multimédia ouvert, cliquez sur 
   Fichier. 
9. Contrastez et sélectionnez Ouvrir. 
10.Pointez un fichier MIDI et sélectionnez-le. Vous 
   trouverez généralement certains fichiers MIDI dans 
   le répertoire \Windows\media. 
11.Vous pouvez alors reproduire des fichiers MIDI en 
   vous servant de la Hardware Wavetable. Cliquez sur 
   le bouton du lecteur multimédia.

9.0 JOUER AVEC UNE WAVETABLE LOGICIELLE 
--------------------------------------- 
1. Cliquez sur Démarrer, pointez sur Paramètres et 
   cliquez sur Panneau de configuration. 
2. Double-cliquez sur l’icône Multimédia. 
3. Sélectionnez Yamaha OPL3SA SoftSynth et cliquez sur 
   OK. 
4. Ouvrez un lecteur multimédia et jouez un fichier MIDI. 
   Utilisez la section Logiciel WT de la console de 
   mixage pour contrôler le volume et la balance de la 
   musique produite par la Wavetable logicielle. 
5. Cliquez sur Démarrer, pointez sur Paramètres et 
   cliquez sur Panneau de configuration. 
6. Double-cliquez sur l’icône OPL3-SAx Config et ajustez 
   le réglage Qualité pour optimaliser la qualité 
   sonore.

-------------------------------------------------------- 
10.0 JOUER AVEC UNE WAVETABLE ET REPRODUCTION SIMULTANEE 
DE FICHIERS WAVE 
-------------------------------------------------------- 
1. Cliquez sur Démarrer, pointez sur Paramètres et 
   cliquez sur Panneau de configuration. 
2. Double-cliquez sur l’icône OPL3SAx Config. 
3. Réglez les paramètres Qualité, Reverb.
4. Cliquez sur OK.

---------------------------------------------------- 
11.0 UTILISATION DE LA WAVETABLE LOGICIELLE DANS UNE 
APPLICATION FENETRE DOS VIRTUELLE 
---------------------------------------------------- 
1. Cliquez sur Démarrer, pointez sur Paramètres et 
   cliquez sur Panneau de configuration. 
2. Double-cliquez sur l’icône OPL3SAx Config. 
3. Réglez les paramètres Qualité, Reverb. 
4. Réglez Sortie MPU401 sur Soft GM. 
5. Cliquez sur OK. 
6. Préparez l’application DOS pour utiliser General MIDI 
   ou MPU401 à l’adresse I/O 330. 
7. Démarrez l’application DOS. La qualité du son devrait 
   être meilleure qu’avec la synthèse FM normale.
